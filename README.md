# 🚀 ReviewGuard — AI-Powered GitHub PR Analyzer

> **Catch risky code before it gets merged. Instantly.**

ReviewGuard is a Chrome Extension + FastAPI backend that brings **real-time AI code review directly into GitHub Pull Requests**.
It detects **high-risk code, AI-generated content, and security issues**, and explains them in **clear, human-readable language** — all inside a sleek sliding panel UI.

---

## ⚡ Demo Experience

> Open any GitHub PR → Go to **"Files changed"** tab → ReviewGuard auto-activates

* ⚡ Panel slides in within seconds
* 🔴 Highlights **high-risk files & lines directly in diff**
* 🤖 Detects **AI-generated code**
* 📖 Explains code behavior in **plain English**
* 💡 Suggests improvements instantly

---

## 🧠 Features

### 🔍 Intelligent Code Analysis

* Detects **security risks** (SQL injection, hardcoded secrets, etc.)
* Identifies **bad coding practices**
* Assigns a **risk score (0–10)** per file

### 🤖 AI Code Detection

* Flags code likely generated by AI
* Provides confidence levels

### 🎯 Line-Level Highlighting

* Pinpoints **exact risky lines in GitHub diff**
* Visual red glow for quick attention

### 💬 Built-in Chatbot (WIP / Upcoming)

* Ask questions like:

  * *"Why is this risky?"*
  * *"How do I fix this?"*
* Context-aware AI responses inside panel

### 🧩 Seamless GitHub Integration

* Works directly on `github.com`
* No clicks needed — auto-detects PR pages

## ⚙️ Setup Instructions

### 1️⃣ Clone the repo

```bash
git clone https://github.com/K-Shreenidhi/Reviewguard.git
cd Reviewguard
```

---

### 2️⃣ Backend Setup (FastAPI)

```bash
python -m venv venv
venv\Scripts\activate   # Windows

pip install -r requirements.txt
```

Create `.env`:

```env
GEMINI_API_KEY=your_api_key_here
```

Run server:

```bash
uvicorn main:app --reload
```

---

### 3️⃣ Expose Backend (ngrok)

```bash
ngrok http 8000
```

Copy HTTPS URL and update in:

```js
content.js

const BACKEND_URL = "https://your-ngrok-url"
```

---

### 4️⃣ Load Chrome Extension

1. Go to: `chrome://extensions/`
2. Enable **Developer Mode**
3. Click **Load unpacked**
4. Select `reviewguard-extension/`
